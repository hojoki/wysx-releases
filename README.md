# WysX — Android releases

This repository holds only the signed Android release builds of **WysX**.
The source code lives in the private `hojoki/wysx-app` repository; releases are
published here automatically by its `android-release` workflow when a `vX.Y.Z`
tag is pushed.

**Download the latest build:** https://hojoki.vercel.app/download

Direct links (always the newest release):

- APK: https://github.com/hojoki/wysx-releases/releases/latest/download/wysx.apk
- Manifest: https://github.com/hojoki/wysx-releases/releases/latest/download/latest.json

Each release also carries a version-named APK (`wysx-X.Y.Z.apk`) and a
`.sha256` file. Only install WysX from these links or from hojoki.vercel.app.
